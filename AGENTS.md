# CreatorZ — Project Blueprint & Context

## 1. Product Vision
CreatorZ is a two-sided creator-brand marketplace tailored for the Indian market, structured around Brief-First Discovery (pitch-based evaluation over follower counts) and Outcome-Linked Reputation.

## 2. Core Personas & Roles
- **Creators:** Pitch creative concepts for open briefs, build verified delivery records, maintain rate cards/portfolios.
- **Brands:** Post open briefs, compare creative pitches, hire for skill/fit, review deliverable milestones.
- **Admin:** Moderate profiles, verification queue, audit logs, and disputes.

## 3. Tech Stack & Styling Rules
- **Framework:** Next.js (App Router, `src/app`).
- **Styling:** Tailwind CSS with modern UI components (Lucide icons, glassmorphism, subtle micro-interactions, dark/light coherence).
- **Design Standard:** Premium, clean aesthetic matching `globals.css` and existing color variables. Avoid raw, generic boilerplate screens.
